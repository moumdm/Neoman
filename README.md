> 🌟 **Newman 是一款 Android 原生本地漫画阅读器**（Kotlin + Jetpack Compose + Material 3），专为手机竖屏与平板横屏阅读设计。
> 所有文件访问通过系统 SAF 完成，**不申请任何权限**，授权由系统管理，清爽又安心 (๑•̀ㅂ•́)و✧

---

## ✨ 为什么选择 Newman？

| | 特性 | 说明 |
|:---:|---|---|
| 🔌 | **完全离线** | 不联网、不收集任何数据、不消耗任何流量 |
| 🔓 | **零权限设计** | 全部文件访问走系统 SAF，无需存储权限 |
| 📦 | **全格式直读** | 无需提前解压，点开就看 |
| 📱📱 | **双端适配** | 网格自适应、双页跨页、横竖屏皆宜 |
| ⚡ | **极速翻页** | ZIP 中央目录随机访问 + 大容量缓存 + 两段式加载 |

## 📚 格式支持（全部本地直读）

| 格式 | 支持方式 |
|---|---|
| 🗜️ ZIP / CBZ | 🚀 中央目录随机访问 —— O(1) 跳页/回翻，打开书籍无需顺序扫描整包；不可 seek 时自动回退顺序流 |
| 🗜️ RAR / CBR | junrar 8.1.1（RAR4 + RAR5），首次打开预处理到私有缓存，之后零延迟 |
| 🗜️ 7Z / CB7 | commons-compress 1.28.0，同上 |
| 📄 PDF | 系统 PdfRenderer 渲染，首次打开预渲染 |
| 📕 EPUB | container.xml → OPF → spine 按阅读顺序取图，固定版式图像 EPUB 完美支持 |
| 📙 MOBI / AZW / AZW3 | PDB 记录魔数扫描（🧪 实验性，复杂 KF8 可能不全） |
| 🖼️ JPG / PNG / WebP / BMP / GIF | 单张图片或整个文件夹直读，长图自动切片为条漫式虚拟页 |

> ⚠️ 加密压缩包暂不支持

## 🎨 阅读体验

### 🧭 阅读方向 & 页面布局
- **三种阅读方向**：从右到左（日漫）➡️⬅️ / 从左到右 / 从上到下（条漫连续滚动，无分页切割感）
- **方向 / 布局 / 翻页效果按书记忆** 🧠：只对当前这本书生效，不受全局设置影响；选「跟随全局」恢复联动
- **底部菜单快捷切换**：`方向` `效果` 一键循环，立即生效
- **单页 / 双页跨页**：平板横屏自动适配，RTL 模式右页在前

### ⏩ 翻页方式
- 👆 点击翻页：左右 30% 区域（方向感知），中间呼出菜单
- 👉 手势滑动
- 🔊 音量键上下翻页（可开关）
- 🌊 条漫自动下滑（0~3000 px/s，一键即用，滚到底自动停）

### 🔍 画面处理
- **横向翻页**：0.5~100 倍无级缩放，可一直放大到看清像素点 🔬，放大后单指拖动看细节，双击快速放大
- **条漫整体缩放**：捏合时**整条漫画（所有页）等比放大**，以手指位置为精确锚点，放大后横向拖动平移、纵向照常滚动，双击 1x/2x 切换
- ⚡ **两段式加载**：快速翻页先显示约一屏大小的预览（毫秒级出图），高清解码后台自动替换
- ✂️ 白边自动裁剪 · 🔄 0°/90°/180°/270° 旋转 · 🪟 横幅跨页自动拆页（拆分顺序随阅读方向）
- 🎨 背景颜色：纯黑 / 深灰 / 纯白 / 米黄

### 💤 阅读细节
- 📍 阅读进度自动记忆（每本书独立，越界进度按比例映射，新书一律从首页开始）
- 🔖 书签标记与跳转
- 🌗 深色 / 浅色主题 + 跟随系统
- 🌅 护眼暖色滤镜 · ☀️ 自定义屏幕亮度 · 🕯️ 阅读时屏幕常亮（可开关）
- 💾 页位图缓存按设备内存取 64~192MB，配合预取（前 3 后 1 并行解码），大文件快翻如丝般顺滑

## 🗂️ 书库管理

- 🖼️ **封面网格**：自适应列数，显示阅读进度与已看完角标
- 🔃 **排序**：首字母 / 添加时间 × 正序倒序 · **筛选**：全部 / 未观看 / 已看完
- 📍 **滚动位置记忆**：进出阅读器后返回原位
- 🧹 **自动清理失效记录**：源文件已删除的书在刷新书库时自动移除（含书签与封面缓存）；文件恢复后可自动重新上架；授权失效的根目录跳过清理，防止整架误删
- ☑️ **批量管理**：长按或菜单进入多选 —— 全选、批量移除、批量标记已看完
- 🗑️ **删除源文件**：移除时可勾选同时删除磁盘源文件（二次警示）
- 📥 **两种导入**：SAF 文件夹授权扫描（深度 3 层，含读写权限）/ 系统文件管理器「打开方式 → Newman」

## 🚀 快速开始

### 🖥️ 环境要求

- 🧰 Android Studio **Ladybug 2024.1.1** 或更新
- ☕ JDK 17+（Android Studio 自带）
- 🤖 Android SDK Platform 34

### 📲 安装步骤

1. 🔓 用 Android Studio **Open** 打开 `ComicReader` 工程根目录
2. ⏳ 等待 Gradle Sync 完成（首次会下载依赖，可配置国内镜像）
3. 🔌 手机开启「开发者选项 → USB 调试」并连接电脑
4. ▶️ 点击工具栏 **Run 'app'** 即可安装运行

### ⌨️ 命令行编译（可选）

```bash
# Windows
gradlew.bat assembleDebug

# macOS / Linux
./gradlew assembleDebug

# Release 签名包（需先在 app/build.gradle.kts 配置 signingConfig）
./gradlew assembleRelease
```

> 💡 若默认 JDK 过新导致编译失败（5 段式版本号 Kotlin 2.0.20 解析不了），追加：
> `-Dorg.gradle.java.home=<JDK17+路径>`

产物位于 `app/build/outputs/apk/debug/app-debug.apk` 📦

## 📖 使用说明

1. 📂 首页点右上角「**更多 → 导入漫画文件夹**」，选择存放漫画的目录（SAF 授权后可持续访问，重启不失效）
2. 🔍 书架自动扫描 ZIP/CBZ/CBR/7Z/PDF/EPUB/MOBI 文件与纯图片文件夹（深度 3 层）
3. 📖 点击封面进入阅读；**长按封面**进入批量管理或单本操作菜单
4. 🎛️ 阅读中点击屏幕中间呼出菜单：
   - **底部**：页码滑条、方向/效果快捷切换、首页/末页/前后翻页、自动下滑开关
   - **顶部**：返回书架、书名与进度、书签管理、阅读设置
5. 🧠 阅读方向、单双页、翻页效果**按书记忆**；其余为全局设置（书架右上角 → 设置）
6. 🧹 删除文件后只需「刷新书库」，失效记录自动清理

## ⚠️ 已知限制（诚实说明）

- 🧪 **MOBI 为实验性**：对 KF8/AZW3 内部容器可能提取不全
- 🌀 **仿真翻页**为透视旋转近似效果，非完整物理翻页卷曲
- ⏳ RAR / 7Z / PDF 首次打开需要预处理（有进度提示），处理后写入应用私有缓存，可在设置中一键清理
- 🔒 加密压缩包暂不支持
- ✍️ 删除源文件需要文件夹授权包含写入权限（旧版本导入的目录需重新导入一次）

## ❓ 常见问题

<details>
<summary><b>Q：Gradle Sync 很慢 / 失败？</b></summary>

在 `settings.gradle.kts` 中把 `google()` / `mavenCentral()` 替换为国内镜像：

```kotlin
maven { url = uri("https://maven.aliyun.com/repository/google") }
maven { url = uri("https://maven.aliyun.com/repository/central") }
```
</details>

<details>
<summary><b>Q：为什么没有申请任何权限？</b></summary>

全部文件访问通过 Android SAF（存储访问框架）完成，授权由系统管理，无需 `READ_EXTERNAL_STORAGE`。
</details>

<details>
<summary><b>Q：支持哪些 Android 版本？</b></summary>

Android 8.0（API 26）及以上。
</details>

<details>
<summary><b>Q：为什么改了全局设置，某些书没变化？</b></summary>

阅读方向 / 页面布局 / 翻页效果是**按书记忆**的。被单独设置过的书使用自己的记忆值，需在阅读设置中选择「跟随全局」才会恢复联动。
</details>
