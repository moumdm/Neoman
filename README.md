Neoman-本地漫画阅读器

原创作者：joein（moumdm）
软件性质：Android 本地应用 · 完全离线 · 免费

----------------------------------------------------------------
一、软件简介
----------------------------------------------------------------

Newman 是一款 Android 平台的原生本地漫画阅读器，专为手机竖屏与
平板横屏阅读设计。

核心承诺：
  · 完全离线 —— 不联网、不收集任何数据、不消耗任何流量；
  · 零权限设计 —— 所有文件访问通过系统 SAF（存储访问框架）完成，
    无需存储权限，授权由系统管理；
  · 全格式直读 —— 无需提前解压，直接打开压缩包阅读；
  · 手机 / 平板双适配 —— 网格自适应、双页跨页、横竖屏皆可。

支持系统：Android 8.0（API 26）及以上。

----------------------------------------------------------------
二、支持的漫画格式（全部本地直读）
----------------------------------------------------------------

  ZIP / CBZ ......... 流式按需读取，大文件顺序翻页零二次解压
  RAR / CBR ......... junrar 8.1.1（RAR4 + RAR5），首次打开
                      预处理到私有缓存，之后零延迟
  7Z / CB7 .......... commons-compress 1.28.0，同上
  PDF ............... 系统 PdfRenderer 渲染，首次打开预渲染
  EPUB .............. 解析 container.xml → OPF → spine，
                      按阅读顺序取图，固定版式图像 EPUB 完美支持
  MOBI / AZW / AZW3 . PDB 记录魔数扫描（实验性，复杂 KF8 可能不全）
  JPG / PNG / WebP / BMP / GIF ...... 单张图片或整个文件夹直读，
                      长图自动切片为条漫式虚拟页

加密压缩包暂不支持。

三、阅读体验
----------------------------------------------------------------

1. 三种阅读方向
   · 从右到左（日漫）
   · 从左到右
   · 从上到下（条漫连续滚动，无分页切割感）

2. 方向与布局按书记忆
   · 在阅读设置中选择阅读方向 / 页面布局，只对当前这本书生效；
   · 单独设置过的书不再受全局设置影响；
   · 选择「跟随全局」可恢复联动；
   · 设置立即生效，无需退出应用。

3. 单页 / 双页跨页
   · 平板横屏自动适配，RTL 模式右页在前；
   · 单双页切换后视图自动对齐回当前页。

4. 翻页效果
   平移滑动 / 仿真翻页（透视旋转近似）/ 平滑淡入 / 直接切换

5. 翻页方式
   · 手势滑动
   · 点击翻页：左右 30% 区域点击（方向感知），中间呼出菜单
   · 音量键上下翻页（可开关）
   · 自动翻页：0~120 秒可调
   · 条漫自动滚动：0~3000 px/s 可调

6. 画面处理
   · 横向翻页（单页/双页）：0.5~4 倍无级缩放（双指捏合），
     放大后单指拖动看细节，双击快速放大；
   · 条漫模式整体缩放：捏合时整条漫画（所有页）
     等比放大，放大后横向拖动平移、纵向照常连续滚动，
     双击在 1x / 2x 间切换，滚动位置自动补偿不跳变；
     适用于所有可导入的文件格式；
   · 白边自动裁剪（自动去除页面空白边）；
   · 0° / 90° / 180° / 270° 画面旋转；
   · 横幅跨页自动拆页（拆分顺序随阅读方向）；
   · 背景颜色：纯黑 / 深灰 / 纯白 / 米黄。

7. 阅读细节
   · 阅读进度自动记忆（每本书独立）；
   · 书签标记与跳转；
   · 深色 / 浅色主题 + 跟随系统；
   · 护眼暖色滤镜；
   · 自定义屏幕亮度；
   · 阅读时屏幕常亮（可开关）。

----------------------------------------------------------------
四、书库管理
----------------------------------------------------------------

1. 书架
   · 封面网格展示，自适应列数（手机 / 平板皆宜）；
   · 显示阅读进度（已读 x/y）与已看完角标；
   · 排序：首字母正序 / 倒序、添加时间正序 / 倒序；
   · 筛选分类：全部 / 未观看 / 已看完；
   · 滚动位置自动记忆，进出阅读器后返回原位。

2. 导入
   · 「导入漫画文件夹」：SAF 授权目录树深度 3 层扫描，
     自动识别各格式文件与图片文件夹；
     授权同时包含读写权限，用于「删除源文件」功能；
   · 从系统文件管理器「打开方式 → Newman」直接打开单个文件，
     自动落地到应用私有目录，重启不失效。

3. 自动清理失效记录
   · 刷新书库时自动识别源文件已被删除的书，
     自动移除记录、书签与封面缓存；
   · 安全机制：外部导入的副本不参与清理；
     授权失效的根目录下的书跳过清理，防止整架误删；
   · 文件将来恢复（如移动回来）后可自动重新上架。

4. 批量管理
   · 长按书籍或菜单进入多选模式；
   · 全选 / 取消全选（按当前筛选列表）；
   · 批量移除；
   · 批量标记已看完 / 未观看；
   · 系统返回键 = 退出多选模式。

5. 移除与删除源文件
   · 移除：仅从书架列表移除，不删除源文件（防扫描复活）；
   · 删除源文件：移除确认框中勾选「同时删除源文件」，
     连磁盘上的源文件一并删除（二次警示，不可恢复）；
   · 删除失败时（旧目录仅授予读权限）会给出明确提示，
     重新导入一次文件夹即可获得写权限。

----------------------------------------------------------------
五、使用说明
----------------------------------------------------------------

1. 首页点右上角「更多 → 导入漫画文件夹」，选择存放漫画的目录
   （SAF 授权后可持续访问，重启不失效）；
2. 书架自动扫描 ZIP/CBZ/CBR/7Z/PDF/EPUB/MOBI 文件与纯图片
   文件夹（深度 3 层）；
3. 点击封面进入阅读；长按封面进入批量管理或打开单本操作菜单；
4. 阅读中点击屏幕中间呼出菜单；
   · 底部：页码滑条快速跳页、首页/末页/前后翻页、
     自动翻页 / 条漫自动滚动开关；
   · 顶部：返回书架、书名与进度、书签管理、阅读设置；
5. 阅读方向、单双页设置按书记忆；其余为全局设置，
   可在书架右上角「更多 → 设置」中调整默认值；
6. 删除文件后只需「刷新书库」，失效记录自动清理。

六、编译与安装
----------------------------------------------------------------

环境要求：
  · Android Studio Ladybug 2024.1.1 或更新版本
  · JDK 17+（Android Studio 自带；注意过新的 JDK 版本号
    可能不被 Kotlin 2.0.20 编译器识别）
  · Android SDK Platform 34

步骤：
  1. 用 Android Studio「Open」打开 ComicReader 工程根目录；
  2. 等待 Gradle Sync 完成（首次会下载依赖，可配置国内镜像）；
  3. 手机开启「开发者选项 → USB 调试」，连接电脑；
  4. 点击 Run 'app' 安装运行。

命令行编译：
  Windows:  gradlew.bat assembleDebug
            （若默认 JDK 过新，追加
             -Dorg.gradle.java.home=<JDK17+路径>）
  macOS/Linux: ./gradlew assembleDebug

产物：app/build/outputs/apk/debug/app-debug.apk

八、已知限制（诚实说明）
----------------------------------------------------------------

  · MOBI 为实验性：对 KF8/AZW3 内部容器可能提取不全；
  · 仿真翻页为透视旋转近似效果，非完整物理翻页卷曲；
  · RAR / 7Z / PDF 首次打开需要预处理（进度提示），
    耗时取决于设备 IO 与文件大小；处理后写入应用私有缓存，
    可在设置中一键清理；
  · 加密压缩包暂不支持；
  · 删除源文件需要文件夹授权包含写入权限
    （旧版本导入的目录需重新导入一次）。

九、常见问题
----------------------------------------------------------------

Q：Gradle Sync 很慢 / 失败？
A：在 settings.gradle.kts 中把 google() / mavenCentral() 替换为
   国内镜像，例如：
   maven { url = uri("https://maven.aliyun.com/repository/google") }
   maven { url = uri("https://maven.aliyun.com/repository/central") }

Q：为什么没有申请任何权限？
A：全部文件访问通过 Android SAF（存储访问框架）完成，
   授权由系统管理，无需 READ_EXTERNAL_STORAGE。

Q：支持哪些 Android 版本？
A：Android 8.0（API 26）及以上。

Q：为什么改了全局设置，某些书没变化？
A：阅读方向 / 页面布局是按书记忆的。被单独设置过的书使用
   自己的记忆值，需在阅读设置中选择「跟随全局」才会恢复联动。
